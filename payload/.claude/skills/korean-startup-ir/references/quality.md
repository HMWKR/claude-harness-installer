# 검수와 완료 기준

## 실행 순서

1. **사실:** 회사 실적·단계·제품 상태를 원자료와 대조하라. 제목·그림·로고·차트가 근거보다 강하게 말하는지도 보라.
2. **숫자:** 단위·기간·모수·중복·실적/목표·산식·반올림을 확인하라. 여러 PPT·대본·Q&A의 같은 수치를 대조하라.
3. **요구사항:** 실제 공고·지정 양식에 답하는 장표와 증거를 확인하라. 없는 배점·규정을 만들지 마라.
4. **이야기:** 제목만으로 고객·문제·해결·증거·사업성·다음 단계가 이해되는지 보라. HOW가 사용자 행동과 출력까지 연결되는지 확인하라.
5. **파일:** 실제 PPTX에 구조 검사를 실행하라. 이름만 .pptx인 HTML·PDF, 누락 관계, 잘못된 순서를 완료로 처리하지 마라.
6. **시각:** 실제 출력 PPTX의 렌더를 보라. 전체 슬라이드 미리보기로 흐름을 확인하고 각 장의 글씨·줄바꿈·차트·각주를 확인하라.
7. **발표:** 배분 시간과 실제 리허설을 구분하라. 화면과 큐카드로 설명할 때 연결이 자연스러운지 확인하라.

## 시각 체크

| 확인 | 해결 방향 |
|---|---|
| 가장 중요한 메시지가 먼저 보이는가 | 제목·핵심 도식·근거의 위계 조정 |
| 텍스트가 잘리거나 겹치는가 | 문장·구도·여백 수정 후 재렌더 |
| 한글 깨짐·대체 폰트가 있는가 | 실제 설치 글꼴 사용, 발표 환경 확인 상태 명시 |
| 숫자·단위·비교기간이 함께 읽히는가 | 라벨·표 단위·각주 정리 |
| 차트가 원자료의 의미를 유지하는가 | 축·분모·누적·예측 구간·출처 대조 |
| 제품 화면의 상태가 정확한가 | 실제/프로토타입/컨셉 표시, 핵심 영역 확대 |
| 장식이 내용보다 강한가 | 불필요한 장식을 줄이고 설명에 필요한 증거 배치 |
| 장별 표현이 단조로운가 | 브랜드는 유지하며 비교·흐름·증거에 맞는 형식 선택 |
| 마지막 요청이 목적과 맞는가 | 투자·도입·선정·미팅과 필요한 자원/성과 연결 |

## 결함과 수정

- **중대:** 가공 실적, 핵심 계산 오류, 필수 항목 누락, 파일 손상, 핵심 텍스트 잘림. 수정하거나 해당 주장을 제거하고 초안으로 표시하라.
- **중요:** 오해를 부르는 제목·축, 사라진 실적 조건, 불명확한 HOW, 미확인 글꼴 대체. 가능한 범위에서 고치고 남은 영향을 설명하라.
- **미세:** 의미·가독성을 해치지 않는 취향 차이. 범위에 맞춰 정리하고 불필요한 반복을 멈춰라.

허용된 수정부터 수행하라. 오류를 둔 채 진행할지 매번 승인을 요청하지 마라. 사용자가 결정해야 할 사실·제출조건만 질문하라.

## 독립 검토

검토자에게 사용자 요구, 실제 덱, 근거 원장, 원자료를 제공하라. 기대 점수·원하는 결론은 주지 마라. 잘못된 주장과 위치, 답하지 못한 청중 질문, 어려운 HOW/사업모델, 실제 시각 결함과 우선순위를 요청하라.

독립 검토가 불가능하면 직접 같은 질문으로 재검토하라. 임의의 투자 성공 확률을 만들지 마라.

## 변경의 영향과 기록

수치 변경 시 관련 시장·재무·차트·제목·대본·질문을 갱신하라. 레이아웃·글꼴 변경 시 해당 장을 재렌더하라. 오탈자는 영향 장만 확인하되 최종 파일 해시는 새로 기록하라.

해시 검사는 이전 검수 기록의 재사용 오류를 잡는다. 이미지 해시가 같아도 실제로 이미지를 봤다는 사실을 증명하지는 않는다. 수행 기록을 정직하게 남겨라.

| 전달 상태 | 사용 조건 |
|---|---|
| 제작·검수 완료 | 요구·근거 대조와 실제 최종 렌더 모든 장 확인 |
| 제작 완료·시각 검수 미완료 | PPTX는 있지만 렌더 또는 이미지 열람을 못 함 |
| 내용 초안 | 주요 자료·출처·조건이 부족하거나 제작 도구가 없음 |
| 검토 결과 | 생성 대신 검토만 요청받음 |

완료를 투자 성공·공식 평가 인증·모든 PowerPoint 환경의 동일 렌더로 확대하지 마라. 실측하지 않은 시간은 추정으로 밝혀라. 실제 파일과 수행한 확인·남은 확인을 전달하라.
