# 한국 IR의 목적과 제출 맥락

목차: 목적과 열람 방식 → 투자 단계 → 공고와 평가표 → 국내 표현 → 공식 출처.

## 1. 목적과 열람 방식을 따로 정하라

사용자의 현재 요청, 실제 제출처의 조건, 회사 원자료를 우선하라.
한국이라는 이유만으로 PSST, 정해진 장수, 3개년 전망, 특정 산업 지표를 적용하지 마라.
참고 기관의 발표 방식은 그 기관의 사례로 취급하고 국내 공통 표준으로 확대하지 마라.

| 목적 | 청중이 결정할 것 | 내용의 중심 | 마지막 요청 |
|---|---|---|---|
| 투자유치 | 후속 검토와 투자 여부 | 고객 문제, 제품, 성과, 수익구조, 성장 경로, 팀, 자금과 다음 성과 | 확인된 투자 요청 또는 후속 미팅 |
| AC·데모데이 | 더 알아볼 이유와 프로그램 적합성 | 가장 강한 증거, 실제 제품, 차별성, 성장 단서 | 미팅·소개·프로그램 참여 등 실제 목적 |
| 창업경진대회 | 해당 대회의 기준 충족 | 현재 평가표에 대응하는 문제·실행·차별성·팀 증거 | 대회 목적에 맞는 선정·지원 |
| 정부지원사업 | 해당 사업의 적합성과 실행 가능성 | 공고의 평가항목, 개발·검증 계획, 일정, 사업비, 역량 | 공고와 일치하는 지원 요청 |
| 사업제휴·오픈이노베이션 | 함께 검증하거나 도입할 가치 | 상대 과제, 적용 업무, 실증 범위, 성공 조건, 담당과 일정 | PoC 착수·자료 제공·구매 검토 |

다음으로 자료를 소비하는 방식을 정하라.

| 방식 | 설계 기준 | 검수 기준 |
|---|---|---|
| 발표용 | 말의 흐름을 지원하는 메시지·시각자료를 중심에 두고 설명은 대본으로 이동 | 제한시간, 화면과 발화의 일치, 멀리서 읽기, 전환과 시연 |
| 독립 열람용 | 발표자 없이도 주장·근거·조건·다음 행동을 이해하게 구성 | 처음 읽는 사람이 추론해야 하는 누락, 수치의 정의, 출처와 부록 |
| 두 버전 | 동일한 원자료에서 목적별로 편집하고 공통 숫자·기준일을 유지 | 버전 사이의 주장 강도·수치·투자 요청 일치 |

사용자가 한 버전만 요청하면 다른 버전의 완성본까지 자동으로 늘리지 마라.
복수 목적이면 같은 파일에 상충하는 요청을 섞기보다 대상별 강조점과 마지막 요청을 조정하라.
투자금, 지원사업비, 고객의 구매대금, 유료 PoC 대금을 같은 의미로 표시하지 마라.

## 2. 투자 단계와 사업 상태에 맞춰 증거를 고르라

투자 라운드의 명칭만으로 제품 완성도나 매출 수준을 추정하지 마라.
현재 회사 자료로 고객 발견, 제품 구현, 사용, 구매, 반복 사용, 운영 가능성을 각각 파악하라.

| 현재 상태 | 먼저 확인할 근거 | 피할 추정 |
|---|---|---|
| 문제 탐색·시제품 이전 | 구체적 고객, 기존 행동, 인터뷰 조건, 창업자의 실행 경험, 다음 실험 | 인터뷰를 매출이나 PMF로 바꾸기 |
| 시제품·초기 실증 | 실제 가능한 기능, 시험 조건, 관측 결과, 남은 제약 | 디자인 시안을 출시 제품으로 표시하기 |
| 초기 판매·사용 | 고객·기간·유무료 구분, 구매와 사용, 유지·재사용, 제공 비용 | 누적 가입자를 현재 활성 고객으로 바꾸기 |
| 확장 준비 | 반복 가능한 획득·제공 방식, 유지, 단위 경제, 채용·운영 역량 | 과거 성장률을 근거 없이 계속 연장하기 |

이 표는 고정 점수표가 아니다. 산업과 구매 주기에 맞는 증거를 선택하라.
딥테크·제조·의료처럼 개발과 도입에 시간이 필요한 사업에는 해당 단계의 기술·현장·인허가 증거를 검토하라.
필요한 규제·인증 상태는 최신 공식 자료와 회사 문서를 대조하고 계획·신청·승인 상태를 구별하라.
SaaS의 ARR, 소비자 서비스의 DAU, 마켓플레이스의 GMV를 다른 사업에 의무 지표로 적용하지 마라.
투자금·기업가치가 미정이면 임의로 채우지 말고 다음 성과와 필요한 자원까지 가능한 범위를 정리하라.

## 3. 공고와 평가표를 읽고 장표에 연결하라

정부지원·경진대회·프로그램 제출은 해당 연도·유형·차수의 공고와 별첨을 확인하라.
변경 공고, 지정 양식, 발표평가 안내, 주관기관의 추가 안내가 있는지 함께 확인하라.
요약 검색 결과나 전년도 자료만 읽고 현재 규정을 확인했다고 쓰지 마라.

1. 사업명, 기관, 연도, 유형, 차수, 공고번호와 변경 여부를 기록하라.
2. 제출 형식, 장수 제한, 표지·부록 포함 여부, 발표와 질의응답 시간을 추출하라.
3. 평가항목의 원명·세부 기준·공개된 배점을 원문 위치와 연결하라.
4. 각 항목에 답할 회사 근거와 장표·부록 위치를 대응시키라.
5. 요구사항이 빠졌거나 서로 충돌하면 그 위치를 남기고 확인 가능한 초안을 계속 작성하라.

| 내부 대응표에 남길 것 | 처리 방법 |
|---|---|
| 원문 위치 | 공식 URL 또는 사용자 제공 파일의 페이지·표·문단 |
| 평가 기준 | 실제 공고의 이름과 의미를 유지 |
| 배점 | 공개된 값만 기록하고 없으면 미공개로 표시 |
| 회사 근거 | 자료 위치, 기준일, 실제 상태, 필요한 추가 자료 |
| 대응 장표 | 항목의 질문에 답하는 장표와 상세 근거 부록 |
| 검토 결과 | 충족·보완 필요·해당 없음과 판단 이유 |

평가항목을 장표 제목에 적었다는 이유로 충족 처리하지 마라.
공개되지 않은 배점·합격선·가점을 만들어 내지 마라.
자체 평가를 제공한다면 공식 점수나 선정 가능성 예측과 구별하라.
PSST는 해당 공고가 채택한 경우 그 공고의 뜻과 범위에 맞춰 사용하라.
사업비의 인정 항목·자부담·기간은 현재 공고와 지침에서 확인하고 다른 사업의 조건을 가져오지 마라.
발표 시간은 배점에 비례해 기계적으로 나누지 말고 중요도·설명 난도·증거량을 함께 고려하라.
필수 조건을 확인하지 못하면 제출용 검수 완료로 표시하지 말고 초안과 남은 확인 항목을 제공하라.

## 4. 국내 청중이 판단할 수 있는 표현을 사용하라

고객과 지불 주체, 도입 결정자, 사용자를 구별하여 설명하라.
제품이 기존 업무의 어느 단계에서 어떤 행동을 바꾸는지 보여 주라.
기업명·고객 로고·협업 표시는 실제 관계와 현재 공개 범위에 맞춰 사용하라.
지역 일자리, 정책 연계, 해외 진출은 회사의 실제 계획이나 제출 기준에 해당할 때 다루라.
대기업 PoC·특허·정부지원 선정 이력이 없다는 이유만으로 모든 사업을 결함으로 판정하지 마라.
"국내 최초", "유일", "경쟁사 없음"은 비교 범위와 근거가 없으면 구체적인 차이로 고쳐라.
과장된 구호보다 대상·행동·결과가 드러나는 한국어를 사용하라.
전문용어는 판단에 필요한 것만 남기고 첫 사용에서 쉬운 뜻을 함께 설명하라.
숫자·시장·실증 수준은 [evidence.md](evidence.md)의 기준으로 검토하라.
