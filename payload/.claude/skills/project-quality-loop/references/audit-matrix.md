# 종합 검수 매트릭스

이 문서는 프로젝트 유형과 위험도에 맞는 검수 항목을 선택하기 위한 카탈로그다. 모든 항목을 무조건 실행하지 말고, 프로젝트 분류·사용자 여정·위험 모델에 따라 `필수`, `권장`, `비적용`으로 표시한다.

## 1. 모든 프로젝트 공통

### 1.1 요구사항과 범위

- 사용자 요청과 저장소 문서가 충돌하는지 확인
- 기능 요구사항, 비기능 요구사항, 제외 범위 명시
- 요구사항마다 구현·테스트·증거 연결
- 성공 기준이 관찰 가능하고 판정 가능한지 확인
- 숨겨진 가정과 미확정 의사결정 기록
- 요청하지 않은 기능 확장 여부 확인
- 삭제·변경된 기존 기능의 영향 확인

### 1.2 구조와 정적 품질

- 빌드, 구문, 타입, 린트, 포맷
- 죽은 코드, 중복 코드, 순환 의존성
- 하드코딩된 비밀·URL·경로·환경 값
- 예외 처리와 오류 전파
- 공개 API와 내부 구현의 경계
- 구성 파일과 실제 코드의 불일치
- 사용되지 않는 의존성, 취약하거나 오래된 의존성
- 테스트 가능한 구조와 의존성 주입

### 1.3 기능 정확성

- 정상 입력과 예상 결과
- 최소값·최대값·빈 값·null·잘못된 형식
- 중복 요청·중복 클릭·재실행
- 부분 성공과 부분 실패
- 취소, 타임아웃, 재시도
- 상태 전이의 유효성
- 데이터 저장 후 재조회 일치
- 새로고침·재시작 후 상태 유지

### 1.4 보안·개인정보·안전

- 인증과 인가를 분리해 검증
- 서버 측 권한 검증
- 최소 권한과 역할 경계
- 입력 검증, 출력 인코딩, 주입 공격
- 비밀·토큰·개인정보 로그 노출
- 민감 데이터 저장·전송·삭제
- 세션 만료·로그아웃·재사용 방지
- 감사 로그와 변경 추적
- 오용·자동화 남용·대량 작업 위험
- 외부 side effect 승인과 취소 가능성

### 1.5 성능·안정성

- 초기 시작·로딩·처리 시간
- 반복 실행 시 누적 지연과 누수
- 큰 입력·큰 데이터·동시 사용자
- 외부 의존성 지연과 실패
- 캐시 정합성
- 메모리·CPU·디스크·네트워크 사용
- graceful degradation과 복구
- 오류 예산과 관측 지표

### 1.6 문서·운영·인수인계

- 설치·실행·테스트 명령 실제 검증
- 환경 변수와 기본값
- 데이터 마이그레이션·롤백
- 장애 대응과 로그 위치
- 알려진 제한과 지원 범위
- 샘플·스크린샷·API 예제가 현재 구현과 일치
- 릴리스 노트와 변경 영향

## 2. Web UI 검수

### 2.1 DOM Probe

- 필수 요소 존재 여부
- 의미 없는 `div` 클릭 요소
- 중복 ID
- 버튼·링크의 빈 텍스트와 이름
- input-label 연결
- disabled, readonly, hidden 상태
- 잘못된 중첩과 유효하지 않은 HTML
- 동적 렌더링 후 고아 노드
- 상태가 바뀌었는데 DOM에 이전 값이 남는 문제

### 2.2 Accessibility Probe

- 접근성 트리의 role/name/value
- landmark와 heading 순서
- 이미지 대체 텍스트
- 폼 오류와 필드 연결
- live region과 로딩 상태
- 모달의 이름, focus trap, 배경 비활성화
- 키보드 접근과 포커스 표시
- 텍스트·UI 대비
- 확대·리플로우와 200% 줌
- 스크린리더에 숨겨야 할 요소와 노출해야 할 요소

자동 접근성 도구 결과만으로 통과시키지 말고 키보드·포커스·동적 상태를 직접 검증한다.

### 2.3 Layout·Visibility·Occlusion Probe

- viewport 밖으로 넘침
- 가로 스크롤
- 요소 겹침과 잘림
- fixed/sticky 요소가 콘텐츠를 가림
- z-index와 투명 오버레이
- 크기 0, opacity 0, visibility hidden
- 요소 중심점과 주요 클릭 지점의 hit-test
- 긴 텍스트·다국어·큰 글꼴에서 깨짐
- safe-area와 모바일 브라우저 UI
- 스켈레톤에서 실제 콘텐츠 전환 시 레이아웃 이동

### 2.4 Visual Probe와 회귀

- 디자인 시스템 토큰과 실제 색·간격·타이포
- CTA 우선순위와 정보 계층
- 빈 상태, 로딩, 오류, 성공 상태
- 이미지 비율·크롭·품질
- 아이콘·폰트 로딩 실패
- 라이트·다크 테마
- 동적·개인화 영역 마스킹 후 스크린샷 비교
- 동일 환경에서 기준 이미지와 현재 이미지 비교
- 픽셀 차이는 규칙으로, 사용성 판단은 별도로 기록

### 2.5 Responsive Probe

기본:

- 모바일 360~393px급
- 데스크톱 1280~1440px급

위험도 또는 대상 사용자에 따라:

- 태블릿 768px급
- 대형 데스크톱
- Chromium, Firefox, WebKit 계열
- 터치와 마우스
- 세로와 가로 방향

### 2.6 Interaction·Form·Focus Probe

- 단일 클릭과 연속 클릭
- 제출 중 비활성화와 중복 요청 방지
- 클라이언트·서버 오류의 일관된 표시
- 입력값 보존과 초기화
- 자동완성, 붙여넣기, IME 입력
- Enter, Space, Escape, 화살표 동작
- Tab/Shift+Tab 순서
- 모달 열기·닫기 후 포커스 복원
- 스크롤 잠금과 뒤로가기
- 낙관적 업데이트 실패 시 롤백

### 2.7 Network·Console·Storage Probe

- 4xx·5xx·CORS·CSP 오류
- 중복·느린·취소된 요청
- 응답 스키마와 UI 반영 일치
- 인증 토큰 누락·만료·갱신
- JavaScript 예외와 미처리 Promise
- hydration과 렌더링 경고
- 이미지·폰트·소스맵·청크 로딩 실패
- Cookie 보안 속성
- localStorage/sessionStorage에 민감정보 저장
- 로그아웃 후 저장 상태 제거
- 사용자·테스트 간 세션 격리

### 2.8 Performance Probe

- 최초 콘텐츠와 주요 콘텐츠 표시
- 입력 반응성과 긴 task
- 레이아웃 이동
- 번들 크기와 코드 분할

- 느린 3G/CPU 제한 조건

## 10. 검수 깊이 선택

| 위험도 | 최소 깊이 |
|---|---|
| Low | 정적 검사 + 핵심 정상 경로 + 기본 문서 |
| Medium | Low + 실패·경계 + 실제 런타임 + 회귀 |
| High | Medium + 독립 검수 + 보안·권한 + 복구 + 다중 환경 |
| Critical | High + 외부 side effect 승인 + 롤백·복원 실증 + 이중 증거 |

## 11. 비적용 처리

검사하지 않은 항목은 누락시키지 말고 다음 중 하나로 표시한다.

- `N/A`: 프로젝트에 구조적으로 해당하지 않음
- `NOT_RUN`: 해당하지만 환경·권한·시간·도구 때문에 실행하지 못함
- `DEFERRED`: 의도적으로 이후 단계로 연기됨
- `UNKNOWN`: 판단할 정보가 부족함

`NOT_RUN`, `DEFERRED`, `UNKNOWN`은 PASS가 아니다.
